# Code map

One row per module, grouped by top-level package and ordered along the data flow (not alphabetically). The `etl/spec/**` feature definitions are collapsed into a single row. **Reference** cites the thesis section/table/figure a file's output backs; files with no reported output are marked **Tool** (standalone tool) or **Infrastructure** (imported library / plumbing). The last column flags names that mislead or need context, with a suggestion — nothing is renamed here.
